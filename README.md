# Portefólio — Edson Mavie

Site estático em HTML, CSS e JavaScript, pronto para publicação em GitHub Pages ou Vercel.

## Estrutura
- `index.html` — página principal e perfil profissional.
- `index.css` — sistema visual, layout responsivo e estilos partilhados.
- `script.js` — menu móvel e ano automático no rodapé.
- `Project.html` — detalhes dos projectos pessoais.
- `Contact.html` — página de contactos.
- `image/` — fotografias, logótipo e capturas.
- `PDF/` — currículo e documentos de projecto.

## Publicação
Carrega os ficheiros e pastas para o repositório mantendo a estrutura. O ficheiro de entrada é `index.html`.

Nota: os links externos, o e-mail, o LinkedIn e os documentos PDF devem ser confirmados antes da publicação final.
